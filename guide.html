# 神戸2026 PWAの使い方・公開手順 ## 最初に このPWAはアプリ本体を初回に読み込んだ後、オフラインで入力・状態報告の生成ができます。利用者の登録は不要です。入力・記録はlocalStorageに保存し、外部へ送信しません。アプリ本体の取得・更新時は公開先に通信し、ホスティング側には通常のアクセスログが残る場合があります。解析サービス・外部フォント・広告・APIは使用していません。 ホーム画面への追加とオフライン機能は、HTTPSの公開URL（PCの検証はlocalhostも可）で利用します。index.htmlのダブルクリックではPWAになりません。初回・アプリ更新時にはネット接続が必要です。 ## 旧版の記録を引き継ぐ 1. 旧HTMLの「履歴・バックアップ」から「全記録をバックアップ」を押します。 2. 新PWAを開き、同じ欄からJSONを読み込みます。 3. 日付ごとの履歴と要約を確認します。睡眠の小数表記や旧選択肢は変換します。旧「痛みの強さ」は最大値とみなさず詳細欄に注記します。 公開URLが変わると保存先も変わります。PCとスマホ、Safariとホーム画面アプリでは保存領域が別になる場合があります。必要な端末・アプリ側でバックアップを読み込んでください。JSONには個人の記録が含まれるため公開先へアップロードしないでください。 ## 日々の入力 朝は記録日（初期値は今日）を確認し、朝の状態とGarminを入力します。睡眠は時間＋15分刻みです。旧記録の細かい分数は丸めず保持します。「その他」の場所を選ぶと詳細欄が開きます。Garminは手入力です。 練習後は「練習後」タブを開きます。実施日が空欄なら記録日として報告します。練習時間は分（例：1時間30分→90）。記録日は朝と練習後で共通ですが、実施日は別に指定できます。 「状態報告を生成」→「文章をコピー → ChatGPTへ」を押し、元のコーチングチャットに貼り付けます。入力に合わせても自動更新します。コピーできなければ表示文章を長押ししてコピー、またはテキスト保存を使ってください。 赤い入力エラーは修正してください。不正値は記録・報告に採用しません。他の有効な項目は保存します。「この日の入力をリセット」は当日分だけを消し、直前の内容を「前回入力を復元」で戻せます。通常の「前回入力を復元」は最後に編集した記録日を開きます。古い値を今日の健康状態として流用しないため、日付も一緒に復元します。 端末やブラウザのデータ削除、プライベートモード、OSの保存領域整理で記録が消える場合があります。定期的にJSONバックアップを端末に保存してください。ブラウザで保存できない場合は画面に表示します。 ## PCでの起動 公開後はHTTPSのURLをChrome / Edge / Safariで開くだけです。 公開前にWindowsで確認する場合（PythonがあるPC）： 1. ZIPを展開します。 2. 展開先のkobe-pwaフォルダでターミナルを開きます。 3. `python -m http.server 8765 --bind 127.0.0.1` を実行します。 4. `http://localhost:8765/` をブラウザで開きます。 5. 「オフライン利用の準備ができました」を待ちます。 6. 終了はターミナルでCtrl+C。初回キャッシュ後はオフラインでも起動できます。 PCのlocalhostはスマホから開けません。スマホは下記のHTTPS公開URLを使ってください。 ## 無料公開：GitHub Pages 公開者だけGitHubアカウントが必要です。利用者はログイン不要です。GitHub Freeで公開リポジトリを使う構成です。 1. GitHubで新しいPublicリポジトリ（例：kobe-condition）を作成します。 2. ZIP内のkobe-pwaフォルダの「中身」をリポジトリ直下にアップロードします。index.html、app.js、fields.js、style.css、manifest.json、sw.js、guide.html、iconsフォルダ、.nojekyll、README.mdが対象です。フォルダ階層を保ってください。ZIPそのものや個人バックアップはアップロードしません。 3. Settings → Pages → Build and deployment → Source「Deploy from a branch」を選びます。 4. Branch「main」、フォルダ「/(root)」を指定してSaveします。 5. 公開完了後の「Visit site」でURLを確認します。通常は https://ユーザー名.github.io/kobe-condition/ です。 6. URLをスマホに送り、オンラインで最初に開きます。カスタムドメイン・課金サービスは不要です。 公開されるのはツールのコードとアイコンだけです。入力値は端末内です。同じ公開元の別アプリとはlocalStorageが共有されるため、できればこのツール専用の公開元で運用してください。 ## Androidへの追加 Chromeで公開URLを開きます。「ホーム画面に追加」ボタンが出たら押します。出なければChromeのメニュー →「ホーム画面に追加」または「インストールしてショートカットを作成」→「インストール」を選びます（表記はバージョンによって異なります）。ホーム画面のアイコンから開き、オフライン準備完了を確認します。 ## iPhoneへの追加 Safariで公開URLを開き、共有メニュー →「ホーム画面に追加」を選びます。「Webアプリとして開く」が表示される場合はオンにして「追加」。ホーム画面の「神戸2026」から起動し、オンラインでオフライン準備完了を待ちます。iPhoneでは独自インストールボタンが出なくても、この操作で追加できます。 ## オフラインの確認 各端末のホーム画面から一度オンラインで起動し、準備完了表示を確認。その後アプリを閉じ、機内モードで再起動し、入力・生成・再読み込み後の保存を試します。ChatGPTへ送信する際はネット接続が必要ですが、文章の生成とコピーはオフラインでできます。 ## アプリ更新 変更したファイル一式を同時に公開してください。sw.jsのVERSIONを必ず変更してください。オンラインで開くと次版を準備し、既存アプリ・タブをすべて閉じて開き直すと更新します。記録は消しません。更新前にバックアップをおすすめします。 ## 構成 index.html：既存画面を継承 / style.css：レスポンシブ・ダークモード / fields.js：入力定義 / app.js：保存・検証・文章生成 / manifest.json：インストール設定 / sw.js：アプリファイルのオフラインキャッシュ / icons：オリジナルアイコン。 外部ライブラリ、ビルド、データベース、クラウド同期は不要です。 ## 公式資料 - Service WorkerとHTTPS：https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API - GitHub Pages：https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site - Android：https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=ja - iPhone：https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios
